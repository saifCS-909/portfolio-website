## 📖 About

*Chitrali Dry Fruits* is a fully responsive e-commerce platform that brings the pure taste of the mountains to customers across Pakistan. The website features:

- Premium dry fruits sourced directly from Chitrali orchards
- Hand-sorted almonds, walnuts, apricots, and pistachios
- Sun-dried the traditional way
- Fresh delivery anywhere in Pakistan

## 🎯 Features Demonstration

### 🛒 Shopping Cart
- Click *"Add to Cart"* on any product
- Cart badge updates automatically
- Cart data persists after page refresh
- Multiple items stack with quantity

### 🔍 Product Search
- Type a product name in the search bar
- Products filter in real-time
- Clear search to show all products
- Search by name or price

### 🏷️ Category Filters
- Navigate to the *Shop* page
- Click category buttons:
  - *All* - Show all products
  - *Nuts* - Show only nuts
  - *Dried Fruits* - Show only dried fruits
  - *Mixed* - Show mixed products
  - *Gift Boxes* - Show gift boxes

### 📧 Newsletter
- Enter your email in the newsletter section
- Click *"Subscribe"*
- Success notification appears
- Email stored in localStorage

### 📞 Contact Form
- Fill in name, email, subject, and message
- Click *"Send Message"*
- Success notification appears
- Message stored in localStorage

### 🔐 Login/Register
- Switch between *Login* and *Register* tabs
- Toggle password visibility with eye icon
- Form validation included
- Demo functionality with localStorage

### 💬 WhatsApp Integration
- Floating WhatsApp button on Contact page
- Click to open WhatsApp chat
- Pre-filled with business number

## 👨‍💻 Developer Notes

### Customization

| Element | Location | How to Change |
|---------|----------|---------------|
| *Colors* | style.css | Edit #8b2f1a (primary color) |
| *Products* | shop.html | Edit product cards |
| *Content* | HTML files | Edit text in HTML |
| *Images* | images/ folder | Replace with your images |
| *Logo* | index.html | Edit <h1> text |
| *Footer* | All HTML files | Edit footer section |

### Adding New Products
1. Open shop.html
2. Copy an existing product card:
```html
<div class="product-card" data-category="category">
    <img src="images/your-image.jpg" alt="Product Name" />
    <h3>Product Name</h3>
    <div class="price-container">
        <span class="price">Rs. 500</span>
    </div>
    <button class="add-to-cart" data-name="Product Name" data-price="500">Add to Cart</button>
    <a href="#" class="view-btn">View</a>
</div>
